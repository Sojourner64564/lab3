Wikimedia Collector
Консольное Python-приложение для автоматизированного сбора данных о предметной области (личность, объект, событие, животное и т.п.) из проектов Wikimedia.

Возможности
Википедия — поиск и загрузка статей (русская + иноязычные с автопереводом через langlinks): текст, изображение, внутренние гиперссылки.

Викиданные — Q-ID, метки, описания, sitelinks для найденных сущностей.

Викисловарь — определения по заголовкам статей.

Wikimedia Commons — поиск файлов и их метаданные (URL, автор, лицензия, описание).

Изображение дня (Picture of the Day) — скачивается вместе с описанием в текстовый файл.

Выход:

domain_data.json — статьи, изображения, гиперссылки, Викиданные, Викисловарь, Commons, рёбра графа и статистика;

graph.dot — граф связей в формате Graphviz DOT (минимум 30 узлов);

picture_of_the_day.* + picture_of_the_day.txt.

Аргументы:
- query	—	Запрос о предметной области (обязательный)
- --out	wikimedia_output	Каталог для результатов
- --max	35	Максимум статей
- --langs	en,de	Доп. языки для автоперевода (через запятую)
- --no-potd	выкл.	Не скачивать изображение дня

Пример запроса:
 - python wikimedia_collector.py "александр пушкин" --max 35 --langs en,de
