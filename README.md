Wikimedia Collector
Консольное Python-приложение для автоматизированного сбора данных о предметной области (личность, объект, событие, животное и т.п.) из проектов Wikimedia.

Аргументы:
- query	—	Запрос о предметной области (обязательный)
- --out	wikimedia_output	Каталог для результатов
- --max	35	Максимум статей
- --langs	en,de	Доп. языки для автоперевода (через запятую)
- --no-potd	выкл.	Не скачивать изображение дня
